介绍

任务平台开放 API，供第三方系统查询任务数据。所有接口均返回 JSON 格式，无需鉴权，直接调用即可。

当前版本：v1  ·  请求编码：UTF-8

Base URL

http://localhost:5000/api

生产环境请替换为实际部署地址，所有接口路径均以 /api 为前缀。

响应格式

所有接口统一返回以下 JSON 结构：

{
  "code":    0,          // 0 = 成功，非 0 = 失败
  "message": "success", // 提示信息
  "data":    { ... }    // 业务数据，失败时为 null
}

错误码

codeHTTP 状态码说明
0200成功
400400请求参数错误
500500服务器内部错误

错误响应示例

{
  "code":    400,
  "message": "status 参数无效，可选值：pending / processing / completed / failed",
  "data":    null
}

获取任务列表

GET /api/v1/tasks 获取全部任务，按创建时间倒序排列

请求参数

参数名类型必填默认值说明
page integer 可选 1 页码，从 1 开始
per_page integer 可选 20 每页条数，最大 100
status string 可选 — 状态筛选：pending / processing / completed / failed
phone string 可选 — 手机号模糊搜索

请求示例

GET /api/v1/tasks?page=1&per_page=20
# 筛选"处理中"状态，按手机号搜索
GET /api/v1/tasks?status=processing&phone=138

调用示例

cURL

curl "http://localhost:5000/api/v1/tasks?page=1&per_page=20"

Python (requests)

import requests

resp = requests.get(
    "http://localhost:5000/api/v1/tasks",
    params={"page": 1, "per_page": 20}
)
data = resp.json()

if data["code"] == 0:
    for task in data["data"]["list"]:
        print(task["id"], task["phone"], task["status_label"])

JavaScript (fetch)

const resp = await fetch('/api/v1/tasks?page=1&per_page=20');
const { code, data } = await resp.json();

if (code === 0) {
  console.log('total:', data.pagination.total);
  data.list.forEach(t => console.log(t.id, t.phone, t.status_label));
}
