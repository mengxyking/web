介绍

OnlineStats 开放 API，用于上报设备在线状态并查询统计数据。无需鉴权，直接调用。

核心逻辑：每次调用心跳接口，系统自动注册设备并记录当日在线（同一设备当天仅计一次）。 统计维度：产品 → 电脑设备 → 手机设备

Base URL

http://localhost:5001/api

响应格式

{
  "code":    0,          // 0 = 成功，非 0 = 失败
  "message": "success",
  "data":    { ... }    // 失败时为 null
}

错误码

code说明
0成功
400参数缺失或格式错误
403电脑设备已禁用或授权已过期
404产品不存在或已禁用
500服务器内部错误

上报在线心跳

POST /api/v1/heartbeat 设备上线时调用，自动注册设备并计入当日在线

请求体（JSON）

字段类型必填说明
product_key string 必填 产品 Key，在后台「产品管理」中复制
computer_code string 必填 电脑设备唯一标识码（如机器码、MAC地址等）
phone_code string 必填 手机设备唯一标识码（如IMEI、设备序列号等）

请求示例

POST /api/v1/heartbeat
Content-Type: application/json

{
  "product_key":   "pk_a1b2c3d4e5f6...",
  "computer_code": "COMP-MAC-AA:BB:CC:DD:EE:FF",
  "phone_code":    "PHONE-IMEI-123456789012345"
}

成功响应

{
  "code": 0,
  "message": "success",
  "data": {
    "product":          "我的产品",
    "date":             "2026-05-14",
    "computer_code":    "COMP-MAC-AA:BB:CC:DD:EE:FF",
    "computer_status":  "active",
    "total":            2,
    "new_phones":       0,
    "new_computer":     false,
    "phone_statuses": {
      "PHONE-IMEI-001": "active",
      "PHONE-IMEI-002": "disabled"
    }
  }
}

字段说明

字段类型说明
productstring产品名称
datestring统计日期
computer_codestring电脑设备码（原样返回）
computer_statusstringactive — 正常；电脑被禁用时直接返回 403
totalint本次上报的手机设备数量
new_phonesint本次首次注册的手机数
new_computerboolean是否首次注册的电脑设备
phone_statusesobject每台手机的状态：active（正常）、disabled（已禁用）、expired（授权已过期）
幂等性：同一设备组合当天多次调用只计一次在线，不会重复统计。建议客户端每隔 5 分钟调用一次作为心跳保活。

设备禁用 / 授权到期说明

管理员可对电脑/手机设备执行禁用操作，并可设置有效期（默认首次上线后 5 天试用期）。超期或被禁用的设备心跳请求将受到限制。

电脑设备被禁用

当上报的 computer_code 对应电脑已被禁用时，接口直接返回 403：

{ "code": 403, "message": "电脑设备已禁用", "data": null }

电脑设备授权已过期

当电脑设备超过有效期（未设置则为首次上线后第 5 天）时，接口直接返回 403：

{ "code": 403, "message": "电脑设备授权已过期", "data": null }

客户端收到 403 后应停止重试并提示用户联系管理员。

手机设备被禁用或已过期

当 phone_codes 中部分手机被禁用或授权过期时，接口仍返回 200，但 phone_statuses 中对应手机的值为 "disabled" 或 "expired"，且该手机不会计入当日在线统计：

{
  "code": 0,
  "message": "success",
  "data": {
    ...
    "phone_statuses": {
      "PHONE-IMEI-001": "active",
      "PHONE-IMEI-002": "disabled",
      "PHONE-IMEI-003": "expired"
    }
  }
}

客户端应根据 phone_statuses 中各手机的状态决定是否为对应设备提供服务。

有效期规则

情况有效期
未设置有效期（默认试用）首次上线日期 + 5 天
管理员已设置有效期以设置日期为准
管理员清除有效期恢复为首次上线 + 5 天试用期

查询今日统计

GET /api/v1/stats 查询今日在线汇总数据

Query 参数

参数类型必填说明
product_key string 可选 不传则返回全平台汇总，传则只返回该产品数据

响应示例

{
  "code": 0,
  "message": "success",
  "data": {
    "date":             "2026-05-12",
    "computers_online": 15,
    "phones_online":    42
  }
}

调用示例

cURL

curl -X POST http://localhost:5001/api/v1/heartbeat \
     -H "Content-Type: application/json" \
     -d '{"product_key":"pk_xxx","computer_code":"COMP-001","phone_code":"PHONE-001"}'

Python (requests)

import requests
import time

def heartbeat(product_key, computer_code, phone_code):
    resp = requests.post(
        "http://localhost:5001/api/v1/heartbeat",
        json={
            "product_key":   product_key,
            "computer_code": computer_code,
            "phone_code":    phone_code,
        },
        timeout=10
    )
    return resp.json()

# 每 5 分钟上报一次
while True:
    result = heartbeat("pk_xxx", "COMP-001", "PHONE-001")
    print(result)
    time.sleep(300)

JavaScript (fetch)

async function heartbeat(productKey, computerCode, phoneCode) {
  const resp = await fetch('/api/v1/heartbeat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      product_key:   productKey,
      computer_code: computerCode,
      phone_code:    phoneCode,
    })
  });
  return resp.json();
}

// 调用示例
heartbeat('pk_xxx', 'COMP-001', 'PHONE-001').then(console.log);
